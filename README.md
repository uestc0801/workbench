# 个人可视化工作台

液态玻璃风格的个人日常管理工作台。纯 HTML/CSS/JS,零依赖、完全离线运行,**适配安卓手机与桌面浏览器**。

## 快速开始

- **直接双击 `index.html`** 即可使用(或右键用浏览器打开)。
- 也可在项目目录运行 `python3 -m http.server 8080` 后访问 `http://localhost:8080`。
- 首次打开默认进入「工作台概览」。所有数据保存在浏览器本地(`localStorage` 键 `wb.data.v1`),无需注册登录。

## 全局能力

- **☁️ 云端同步(跨设备 / 云备份)**:在「设置 → 云端同步」里填入你的 **Gitee/GitHub 私有仓库**与个人令牌,数据自动上传到仓库的 `wb-data.json`。电脑、手机连同一个仓库即数据互通 + 云端备份,换设备也能恢复历史数据。支持立即上传/下载、自动定时同步、测试连接。配置教程见设置页。
- **全局搜索**:顶部搜索待办、书籍、灵感、复盘、单词、摘抄,点击直达。
- **统一提醒**:喝水/阅读/英语/运动/自定义/每周深度思考,页面内弹窗 + 系统通知(授权后)。
- **每日自动归档**:每日首次打开自动把昨日各模块数据聚合归档,复盘历史可回溯。
- **数据可视化**:环形图、进度条、柱状图、折线图、迷你图,均带悬浮详情、深浅双模式配色。
- **语音朗读**:兼容小米自带浏览器与 Chrome;中文/英文自动选语音。若仍无声,确认浏览器允许播放声音、页面未被静音。

## 使用须知(补充)

- **数据位置**:默认存在各浏览器本地 localStorage(键 `wb.data.v1`)。电脑与手机的本地数据互不相通,想互通请开启「云端同步」并让两端都连同一个仓库。
- **热点跳转**:抖音/B站/知乎热点,能拿到具体链接的(B站视频、抖音搜索)会尝试唤起 App 并直接打开具体内容;拿不到时降级为平台入口,条目上有明确标签。
- **单词自动补全**:添加单词时输入英文后点「✨ 自动补全」,自动填音标/释义/例句(内置专业词库 + 在线词典兜底,离线可用内置库)。

## 使用须知

- **定时提醒需保持页面打开**(浏览器限制)。页面刷新后提醒调度自动恢复;若已授权系统通知,即使切到后台也会推送。
- **语音转文字**依赖 Chrome/Edge 等浏览器的 Web Speech API(需联网);不支持时自动回落为文字输入。
- **热点跳转 App**:安卓/手机浏览器点击热点会先尝试唤起对应 App(抖音/B站/知乎),失败自动打开网页。
- **黄历/星座**由内置算法本地推算,离线可用;运势内容为程序化生成的参考文案。

## 文件结构

```
index.html          应用外壳
css/style.css       液态玻璃设计系统(深浅主题/毛玻璃/动效/响应式)
js/core.js          数据存储、日期、提醒调度、全局 UI、搜索、语音
js/charts.js        SVG 图表库(环形/柱状/折线/迷你/仪表)
js/lunar.js         农历换算、黄历、星座
js/modules/*.js     十一个功能模块
js/main.js          导航与启动
```

## 数据备份

设置 → 数据管理 → 导出数据,可生成 JSON 备份文件;迁移到其他设备时用「导入数据」恢复。
